Daftar Do'kon
=============
1) Papkadagi index.html faylini brauzerda (Chrome) oching.
2) Boshliq sifatida ro'yxatdan o'ting, mahsulot va ishchi qo'shing.
3) Ma'lumotlar shu brauzerda saqlanadi (yakka rejim).

Eslatma: boshqa telefonlar bilan umumiy ishlash uchun ilova
server (ma'lumotlar bazasi) bilan ulanishi kerak. Bu zip ichida
server yo'q, shuning uchun ishchi ham shu qurilmada kiradi.
Birinchi ochilishda animatsiya uchun internet kerak emas, lekin
fayl ichidagi barcha kod o'z-o'zidan ishlaydi.
